Privacy Policy.

This editable policy describes the information this demonstration website may process. Review and adapt it for your actual hosting, analytics and legal requirements before publication.

ON THIS PAGEInformationLocal storageAI processingContact

Information this site may process

When you use the solver, the question text and selected subject are sent to this site's server so it can request an AI-generated answer. The hosting provider may also process standard technical request data, such as an IP address, browser details and request time, according to its configuration and policies. This project does not include analytics or user accounts by default.

Please do not enter passwords, contact details, health information or other sensitive personal information in a question.

Local storage and question history

When an answer is returned, the site can save the question, subject, answer and date in your browser's local storage to provide the history feature. This information remains on that browser unless you clear it or remove individual entries. It is not synced across devices by this project. Other people using the same browser profile may be able to see it.

AI provider processing

To generate a response, the server sends your question and selected subject to the configured AI provider, Groq, through its API. The provider processes that content under its own terms and privacy practices. Review the provider's current documentation before deploying this site. The API credential is held on the server and is not intended to be exposed to site visitors.

AI answers may be wrong or incomplete. Verify important information using reliable sources.

Contact form and communications

The contact form in this project performs validation in your browser only. It does not transmit or store submissions. If a backend service is added later, update this policy to explain what it collects, why, and how long it is retained.

Changes to this policy

This text is a starting point, not legal advice. The site operator should update it to reflect actual deployment practices and applicable requirements. Material changes should be reflected here with an updated date.

Questions

Questions about this policy can be shared through the contact page. The current demo form does not deliver messages.
